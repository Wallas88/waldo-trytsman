# Waldo Trytsman — Developer Profile

A cinematic, accessible full-stack developer profile built with React and Vite. The visual direction combines dark-fantasy artwork with a restrained game-interface language while keeping the content readable, responsive, and useful.

## Run locally

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```

## Update profile content

Personal details, capabilities, principles, and project cards live in `src/profile.js`. Update that file rather than editing copy throughout the components.

## Deploy

The generated `dist/` directory can be deployed to GitHub Pages, Netlify, Cloudflare Pages, or another static host. The Vite build command is `npm run build` and the publish directory is `dist`.

Artwork in `public/art/` was supplied by Waldo Trytsman for this profile. It is not offered for reuse independently of this project.
